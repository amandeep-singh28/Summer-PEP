(ii)Plan & Execute Pattern
In the Plan & Execute Pattern, the AI agent performs two distinct phases:
- Planning Phase
    Understand the user's goal.
    Break the task into smaller steps.
    Decide the order in which the steps should be executed.
- Execution Phase
    Execute each step one by one.
    Use tools whenever required.
    Produce the final output.

Question
    |
Plan
    |
Step 1
    |
Step 2
    |
Output

(iii)TOT(Tree of thoughts)
The Tree of Thoughts pattern enables an AI agent to:
- Generate multiple possible ideas (thoughts).
- Evaluate each idea.
- Keep the best ones.
- Discard poor ones.
- Continue exploring until it reaches the best solution.

            ▼          ▼          ▼
        Evaluate    Evaluate   Evaluate
        Good/Bad    Good/Bad   Good/Bad
            │          │          │
            └──Keep Best Thought───
                        │
                        ▼
                Continue Reasoning
                        │
                        ▼
                Final Solution

(iv)Reflection Pattern
In the Reflection Pattern, the task is completed in multiple stages:
- Solver Agent solves the problem.
- Reviewer (Reflection) Agent evaluates the solution.
- Feedback is generated.
- Solver Agent improves the solution using the feedback.
- The cycle can repeat until the solution is satisfactory.

Question
    │
    ▼
Solver Agent
(Solve the problem)
    │
    ▼
Reviewer Agent
(Evaluate the solution)
    │
    ▼
Generate Feedback
    │
    ▼
Retry / Improve Solution
    │
    ▼
Final Output

(v)Modified Reflection Pattern
The Modified Reflection Pattern consists of four stages:
(i) Multiple Solver Agents
- Each agent independently solves the same problem.
- They may use different reasoning styles or approaches.
(ii) Critic Agent
- Reviews every solution.
- Identifies mistakes, strengths, and weaknesses.
- Suggests improvements.
(iii) Judge Agent
- Reads all solutions along with the critic's feedback.
- Selects the best solution (or combines the best parts of multiple solutions).
(iv) Final Output
- The user receives the highest-quality answer
